# 教案：植物大發現

- 適用對象：國小三年級 · 自然科學
- 教學時間：40分鐘
- 教材模式：引導模式

## 學習目標

- 能說出植物的根、莖、葉、花四個主要部位及其功能。
- 能說明莖如何把水分從根運送到葉，並理解陽光對植物生長的影響。
- 能描述植物的一生（種子→發芽→生長→開花→結果），並舉出植物傳播種子的方式。
- 能舉出植物在生活中的應用，並養成珍惜植物資源、資源永續（落葉堆肥）的態度。

## 教學流程

| 階段 | 時間 | 教師活動 | 學生活動 | 對應頁籤 |
| ---- | ---- | -------- | -------- | -------- |
| 引起動機 | 5分 | 出示幼苗動畫，提出四個核心問題 | 觀察身邊植物、分享舊經驗 | 學習任務 |
| 發展活動一 | 10分 | 講解植物構造與水分輸送圖 | 對照圖說出根莖葉花功能 | 原理探索 |
| 發展活動二 | 10分 | 引導操作陽光滑桿、播放生長模擬 | 拖動滑桿觀察、預測並驗證 | 互動實驗／動畫模擬 |
| 綜合活動 | 10分 | 帶領討論生活情境卡片、進行闖關 | 點按卡片、作答 7 題闖關 | 生活應用／闖關大挑戰 |
| 延伸學習 | 5分 | 介紹自學影音與博物館資源 | 課後自行觀看延伸影片 | 自學資源 |

## 評量方式

- 形成性：互動實驗操作與課堂問答。
- 總結性：闖關大挑戰 7 題答對率。
- 實作延伸：嘗試蔥再生或落葉堆肥的家庭小觀察（選做）。
