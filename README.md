# 植物大發現

「植物大發現」是給國小三年級自然科學使用的互動式數位教材。

## 教材資訊

- 適用對象：國小三年級
- 科目：自然科學
- 學習時間：40分鐘
- 教材模式：引導模式
- 目前版本：v1.1.0
- GitHub Pages：https://prayer168.github.io/plant-discovery-interactive-learning/

## 學習目標

- 認識植物根、莖、葉、花的外部構造，並能連結各自的功能。
- 知道植物需要水、空氣、養分與陽光才能維持生命與生長。
- 了解植物的構造與行為如何幫助生存與繁衍（如種子傳播）。
- 察覺植物與日常生活、自然資源的關係，培養資源永續（如落葉堆肥）的觀念。

## 頁籤內容

1. 觀察植物
2. 植物的莖
3. 植物的葉與根
4. 植物的繁衍與資源永續
